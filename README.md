# Home Improvement Loan Scorecard - interactive demo

Live page: https://leelinwang.github.io/faproject/

An interactive version of the final IS453 scorecard (11 characteristics, cutoff 600, 600 = odds 1 : 9.72, PDO 20). Enter an application or pick an example to see the points for each characteristic, the score, odds, probability of default and expected profit.

- `index.html` - the published page (a copy of `interactive demo/scorecard_demo.html`)
- `interactive demo/build_demo.py` - regenerates the page from the model files in `data/` (run from the project folder)
- `interactive demo/template.html` - page layout and scoring logic

The notebooks (Steps 0-7) are on the `main` branch.
